# JincSAE

**Jornalista Inclusivo Social Automation Engine**

JincSAE is an editorial automation engine designed to transform published articles from Jornalista Inclusivo into platform-specific social media content. It operates as a distribution and transformation layer rather than a generic AI text generator.
